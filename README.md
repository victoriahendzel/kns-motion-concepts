# KNS Motion Concepts

Scroll-driven animation concepts for KNS Building Restoration, built from
the existing KNS design-system illustrations (etched NYC artwork) and
photography from knsbuildingrestoration.com.

Static site — `index.html` + `assets/`. Animation: GSAP 3 + ScrollTrigger
(inlined). Techniques: sketch "draw-out" mask reveals, scroll-scrubbed pinned
storytelling, annotated photo overlays, count-up stats, before/after slider.

Prepared by Victoria Hendzel · August 2026. Illustrations & photos © KNS.
